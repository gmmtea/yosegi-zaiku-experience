# 箱根寄木細工体験

箱根寄木細工のコースター作り体験向けデザインシミュレーターです。

## 遊び方

1. パレットから木材（木の種類・形）を選ぶ
2. キャンバスをクリックしてピースを配置
3. ↺ ↻ でキャンバス全体を30°ずつ回転
4. ＋ － でグリッドを拡大・縮小（5段階）
5. ↑ ↓ ← → でグリッドを移動
6. 🧹ボタンで消去モードに切り替えてピースを削除
7. 「完成！」でデザインを画像として保存

## 仕様

- 正三角形グリッド（60°基調）
- 菱形＝正三角形×2
- 使用木材：ミズキ・ホオノキ・ウルシ・チャンチン・ウォールナット
- 全消去で吹っ飛びアニメーション
- 完成時に紙吹雪演出
