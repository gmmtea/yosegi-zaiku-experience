# 箱根寄木細工体験

箱根寄木細工体験をブラウザ上で体験できるインタラクティブアプリです。

## 遊び方

1. 上段のパレットから木材（木の種類・形）を選ぶ
2. キャンバスをクリック、またはドラッグ＆ドロップでピースを配置
3. 菱形はカーソルを近い辺に寄せると向きが変わる
4. ↺ ↻ ボタンでキャンバス全体を30°ずつ回転
5. 「完成！」で画像として保存

右クリックで置いたピースを削除できます。

## 仕様

- 正三角形グリッド（60°基調）
- 菱形＝正三角形×2
- 使用木材：ミズキ・ホオノキ・ウルシ・チャンチン・ウォールナット

## 技術

HTML / CSS / JavaScript
