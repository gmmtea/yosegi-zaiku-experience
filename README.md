# 箱根寄木細工体験

箱根寄木細工体験をブラウザ上で体験できるインタラクティブアプリです。

## 遊び方

1. パレットから木材（木の種類・形）を選ぶ
2. キャンバスをクリックしてピースを配置
3. ↺ ↻ でキャンバス全体を30°ずつ回転
4. ＋ － でグリッドを拡大・縮小（5段階）
5. ↑ ↓ ← → でグリッドを移動
6. 🧹ボタンで消去モードに切り替えてピースを削除
7. 「完成！」で画像として保存

## 仕様

- 正三角形グリッド（60°基調）
- 菱形＝正三角形×2
- 使用木材：ミズキ・ホオノキ・ウルシ・チャンチン・ウォールナット

## 技術

HTML / CSS / JavaScript
