# 箱根寄木細工体験 デザインシミュレーター

箱根寄木細工のコースター作り体験向けデザインシミュレーターです。

🔗 https://yosegi-zaiku-experience.vercel.app/

## 遊び方

1. パレットから木材（木の種類・形）を選ぶ
2. キャンバスをタップ・クリックしてピースを配置
3. ↺ ↻ でキャンバス全体を30°ずつ回転
4. ＋ － でグリッドを拡大・縮小（5段階）
5. ↑ ↓ ← → でグリッドを移動
6. 🧹ボタンで消去モードに切り替えてピースを削除
7. 「完成！」でデザインを画像保存・URLコピー・Xシェア

## 仕様

- 正三角形グリッド（60°基調）
- 菱形＝正三角形×2
- 使用木材：ミズキ・ホオノキ・ウルシ・チャンチン・ウォールナット
- 最大40ピース（プログレスバー表示）
- undo（一つ戻す）・全消去対応
- 日本語・英語切り替え対応
- 保存用URLでデザインを共有・再現（URLパラメータにエンコード）
